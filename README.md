# Opening 3D Platform - 실행 가이드

한국 창업 패키지 관리 플랫폼으로, 3D 공간 스캐닝 / 3D 가구 에셋 생성 / 골목상권분석 보고서 기능을 제공합니다.

---

## 사전 준비

### 1. 의존성 설치

```bash
cd openingsample
npm install
```

### 2. 환경 변수 설정

프로젝트 루트(`openingsample/`)에 `.env` 파일을 생성하고 아래 키를 설정합니다.

```env
# Supabase (인증 및 데이터 저장)
VITE_SUPABASE_URL=<supabase-project-url>
VITE_SUPABASE_ANON_KEY=<supabase-anon-key>

# World Labs Marble API (3D 공간 스캐닝)
VITE_MARBLE_API_KEY=<world-labs-api-key>

# Segmind SAM API (3D 가구 에셋 생성)
VITE_SEGMIND_API_KEY=<segmind-api-key>

# 공공데이터포털 API (상권분석)
VITE_DATA_GO_KR_API_KEY=<공공데이터포털-api-key>

# Kakao REST API (주소 검색 / 지오코딩)
VITE_KAKAO_REST_API_KEY=<kakao-rest-api-key>

# 서울열린데이터광장 API (추정매출/유동인구 - 선택사항)
VITE_SEOUL_API_KEY=<서울열린데이터광장-api-key>
```

### 3. 개발 서버 실행

```bash
npm run dev
```

서버가 `http://localhost:3000`에서 시작됩니다. 외부 접속도 가능하도록 `0.0.0.0`으로 바인딩됩니다.

## 기능 1: 3D 공간 스캐닝

> **접속:** `http://localhost:3000/scanner.html`
>
> **사용 API:** World Labs Marble API
>
> **필요 환경 변수:** `VITE_MARBLE_API_KEY`

실내 사진 한 장으로 3D Gaussian Splat 공간을 생성하는 기능입니다.

### 사용 방법

**Step 1 - 이미지 업로드**

- 화면에 실내 사진을 드래그 앤 드롭하거나 클릭하여 업로드합니다.
- 여러 장 업로드 후 대표 이미지를 선택할 수 있습니다.
- 텍스트 프롬프트에 원하는 인테리어 스타일을 입력합니다 (예: "modern minimalist cafe").
- 고급 옵션에서 모델 품질을 선택할 수 있습니다:
  - **Marble 0.1-mini** : 빠른 생성 (Draft)
  - **Marble 0.1-plus** : 고품질 생성

**Step 2 - 3D 생성 대기**

- "3D 공간 생성" 버튼을 클릭하면 Marble API로 요청이 전송됩니다.
- 생성에는 약 3~5분이 소요되며, 5초 간격으로 진행 상태를 폴링합니다.
- 진행 상황이 화면에 실시간으로 표시됩니다.

**Step 3 - 결과 확인**

- 생성 완료 후 3D Gaussian Splat 뷰어에서 결과를 확인합니다.
- 마우스/키보드로 3D 공간을 자유롭게 탐색할 수 있습니다.
- 제공되는 결과물:
  - 3D Gaussian Splat 뷰어 (인터랙티브)
  - 360도 파노라마 이미지
  - 썸네일 이미지
  - AI 생성 캡션
- `.spz` 파일을 3가지 품질(100k / 500k / full_res)로 다운로드할 수 있습니다.
- World Labs 외부 3D 뷰어 링크도 제공됩니다.

## 기능 2: 3D 가구 에셋 생성

> **접속:** `http://localhost:3000/furniture.html`
>
> **사용 API:** Segmind SAM 3D API
>
> **필요 환경 변수:** `VITE_SEGMIND_API_KEY`

가구/장비 사진에서 특정 물체를 클릭하여 3D GLB 모델을 생성하는 기능입니다.

### 사용 방법

**Step 1 - 이미지 업로드**

- 3D로 변환하고 싶은 가구 또는 장비 사진을 업로드합니다.
- 드래그 앤 드롭 또는 클릭으로 업로드할 수 있습니다.
- 파일명이 에셋 이름으로 자동 입력됩니다.

**Step 2 - 클릭 포인트 지정**

- 업로드된 이미지 위에서 3D로 변환할 물체를 클릭합니다.
- 2~3개의 클릭 포인트를 찍어 물체의 영역을 지정합니다.
- 클릭 포인트는 번호가 매겨진 마커로 표시됩니다.
- 잘못 찍은 포인트는 개별 삭제하거나 전체 초기화할 수 있습니다.
- 선택사항:
  - **텍스트 힌트** : 물체 종류를 영어로 입력 (예: "chair", "table")
  - **에셋 이름** : 저장 시 사용할 이름
  - **시드 값** : 결과 재현을 위한 랜덤 시드

**Step 3 - 3D 모델 생성**

- "3D 모델 생성" 버튼을 클릭하면 Segmind API로 요청이 전송됩니다.
- 클릭 포인트 좌표가 이미지 좌표계로 변환되어 API에 전달됩니다.

**Step 4 - 결과 확인**

- 생성된 3D GLB 모델을 인터랙티브 뷰어에서 확인합니다.
- 마우스로 회전, 확대/축소, 이동이 가능합니다.
- 제공 기능:
  - GLB 파일 다운로드
  - Supabase `furniture_assets` 테이블에 저장
  - 원본 이미지와 클릭 포인트 오버레이 확인
  - 추론 소요 시간 표시

## 기능 3: 골목상권분석 보고서

> **접속:** `http://localhost:3000/commerce.html`
>
> **사용 API:** 소상공인시장진흥공단(공공데이터포털) + Kakao 지오코딩 + 서울열린데이터광장(선택)
>
> **필요 환경 변수:** `VITE_DATA_GO_KR_API_KEY`, `VITE_KAKAO_REST_API_KEY`, `VITE_SEOUL_API_KEY`(선택)

특정 위치 주변의 상권 현황을 분석하여 보고서를 생성하는 기능입니다.

### 사용 방법

**Step 1 - 위치 설정**

- 분석할 위치를 다음 방법 중 하나로 설정합니다:
  - **주소 검색** : 주소, 건물명, 지하철역 등으로 검색 (Kakao 지오코딩)
  - **현재 위치** : 브라우저 위치 정보 사용
- 분석 반경을 선택합니다: 300m / 500m / 1,000m / 1,500m
- 업종 필터를 설정할 수 있습니다 (선택사항):
  - 음식, 소매, 생활서비스, 관광/여가, 부동산, 숙박, 스포츠, 학문/교육

**Step 2 - 보고서 생성**

- "상권분석 시작" 버튼을 클릭하면 공공데이터포털 API에서 반경 내 상가업소 데이터를 수집합니다.
- 수집된 데이터를 기반으로 아래 항목이 자동 분석됩니다.

**Step 3 - 분석 결과 확인**

보고서에 포함되는 항목:

| 분석 항목 | 설명 |
|----------|------|
| **총 점포 수** | 반경 내 전체 상가업소 수 |
| **점포 밀도** | km² 당 점포 수 |
| **업종별 분포** | 대분류별 점포 수 및 비율 (상위 6개) |
| **인기 업종** | 중분류 기준 상위 카테고리 |
| **프랜차이즈 분석** | 프랜차이즈 vs 개인 점포 비율, 상위 프랜차이즈 |
| **추정매출** (서울 한정) | 점포당 평균 매출, 주요 연령대/성별 |
| **유동인구** (서울 한정) | 총 유동인구, 피크 시간대, 주요 연령대 |
| **점포 목록** | 업종 필터링 가능한 전체 점포 리스트 |

- 분석 결과를 JSON 파일로 내보내기할 수 있습니다.
- 서울 지역의 경우 `VITE_SEOUL_API_KEY` 설정 시 추정매출/유동인구 데이터가 추가됩니다.

## 기능 4: 골목상권 보고서 뷰어

> **접속:** `http://localhost:3000/commerce-report.html`
>
> **데이터 소스:** 골목상권 스크래퍼(기능 5) 결과 JSON 또는 샘플 데이터

골목상권 스크래퍼로 수집한 데이터를 기반으로 리스크 점수, 전문가 추천 등을 포함한 심층 분석 보고서를 생성하고 내보내는 기능입니다.

### 사용 방법

**Step 1 - 데이터 입력**

- 두 가지 방법 중 하나를 선택합니다:
  - **"샘플 데이터 사용"** : 미리 준비된 예시 데이터로 보고서를 즉시 확인
  - **"직접 입력"** : 골목상권 스크래퍼(`npm run scrape:golmok`)의 결과 JSON을 붙여넣기

**Step 2 - 보고서 생성**

- "보고서 생성하기" 버튼을 클릭합니다.
- 입력 데이터를 기반으로 점수 산출, 리스크 판정, 섹션별 분석이 자동 수행됩니다.

**Step 3 - 보고서 확인**

생성되는 보고서에 포함되는 항목:

| 항목 | 설명 |
|------|------|
| **리스크 등급** | LOW / MEDIUM / HIGH 배지 표시 |
| **종합 점수** | 0~100점 게이지 (70+ 녹색, 50~69 주황, 50 미만 빨강) |
| **3대 지표 대시보드** | 점포 수 변화, 매출 변화, 유동인구 변화 (전분기 대비) |
| **종합 현황** | 전체 요약 분석 |
| **점포 현황 분석** | 점포 증감 추세 및 경쟁 현황 |
| **매출 동향 분석** | 매출 변화 추세 분석 |
| **유동인구 분석** | 유동인구 변화 추세 |
| **자치구 내 순위** | 점포/매출/유동인구 순위 (데이터 있을 경우) |
| **업종/매출/인구/지역 상세분석** | 생존율, 월평균 매출, 피크 시간대, 임대료 등 (확장 데이터 있을 경우) |
| **전문가 추천** | 매출/인구/경쟁 동향 기반 맞춤 전략 5가지 |

**Step 4 - 내보내기**

- **"텍스트 복사"** : 서식이 적용된 텍스트 보고서를 클립보드에 복사
- **"HTML 다운로드"** : 스타일이 포함된 독립 HTML 파일로 다운로드 (공유/인쇄용)

### 점수 산출 기준

| 요소 | 반영 방식 |
|------|----------|
| 기본 점수 | 70점 |
| 매출 변화 | 증감 폭에 따라 최대 +/-10점 |
| 유동인구 변화 | 증감 폭에 따라 최대 +/-8점 |
| 신규 점포 경쟁 | 5개 초과 시 -5점 |
| 자치구 내 순위 | 상위 비율에 따라 최대 +10점 |

## 기능 5: 골목상권 스크래퍼 (CLI)

> **실행:** 터미널에서 `npm run scrape:golmok` 실행
>
> **데이터 소스:** golmok.seoul.go.kr (서울시 우리마을가게 상권분석서비스)
>
> **필요 사항:** Node.js, Puppeteer (npm install 시 자동 설치)

서울시 골목상권 분석 사이트를 자동으로 탐색하여 상권 데이터를 수집하는 Puppeteer 기반 웹 스크래퍼입니다.

### 실행 방법

```bash
npm run scrape:golmok
```

내부적으로 `npx tsx scripts/golmokScraper.ts`를 실행합니다.

### 스크래퍼 동작 과정

1. Puppeteer로 헤드리스 Chrome 브라우저를 실행합니다.
2. golmok.seoul.go.kr에 접속하여 지역/업종을 선택합니다.
3. 지도에서 분석 지점을 설정하고 분석 반경(500m/1km)을 지정합니다.
4. 보고서 페이지의 각 탭(업종분석, 매출분석, 인구분석, 지역분석)을 순회하며 데이터를 추출합니다.
5. 결과를 JSON으로 출력합니다.

### 수집 데이터 항목

| 카테고리 | 수집 항목 |
|----------|----------|
| **기본 정보** | 행정동명, 분석 분기, 업종, 요약 인사이트 (4~5개) |
| **변동 지표** | 점포 수 변화, 매출 변화, 유동인구 변화 (전분기 대비) |
| **자치구 내 순위** | 점포 순위, 매출 순위, 유동인구 순위, 전체 행정동 수 |
| **업종 분석** | 1/3/5년 생존율, 평균 영업 기간, 개·폐업 수, 프랜차이즈 비율 |
| **매출 분석** | 총 매출, 월평균 매출, 주중/주말 비율, 성별 비율, 피크 요일/시간대 |
| **인구 분석** | 총 유동인구, 직장/거주 인구 비율, 성별 비율, 피크 시간대 |
| **지역 분석** | 평균 임대료, 임대료 추세, 상업 밀도, 주거/상업 비율 |

### 결과 활용

스크래퍼 출력 JSON은 **기능 4 (골목상권 보고서 뷰어)** 의 "직접 입력" 기능에 붙여넣어 심층 분석 보고서를 생성할 수 있습니다.

```
[스크래퍼 실행] → JSON 결과 복사 → [commerce-report.html] → "직접 입력"에 붙여넣기 → 보고서 생성
```

## 기술 스택

| 분류 | 기술 |
|------|------|
| 프론트엔드 | React 19 + TypeScript + Vite |

| 스타일링 | Tailwind CSS (CDN) |
| 차트 | Recharts (상권분석 보고서) |
| 외부 API | World Labs Marble, Segmind SAM 3D, 공공데이터포털, Kakao REST |
